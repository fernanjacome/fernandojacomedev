# Versión anterior

`previous-portfolio/` conserva el estado local anterior al rediseño, incluidos componentes, estilos, manifiestos de dependencias y assets. No forma parte de la aplicación activa. Algunos archivos ya estaban modificados respecto de Git al comenzar la revisión.

El archivo no es una aplicación instalable independiente: conserva material para consulta y recuperación. El CV de 2025 y las texturas antiguas no se sirven desde la nueva web.
